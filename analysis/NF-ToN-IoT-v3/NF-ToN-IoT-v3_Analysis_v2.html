Why this notebook exists¶

v1 answered a useful first question (what is in the file, are attacks contiguous after benign removal?) but exposed problems:

  • its attack samples were the first 20,000 rows of each episode, not representative samples;
  • its benign sample came from the first 1M rows, which cover only ~18 minutes of the scanning episode;
  • several "full-file" statements were actually sample-based;
  • graph-window feasibility and host/relation confounding were not measured.

v2 keeps v1 untouched as a historical record and repeats the analysis with explicit provenance. It follows the audit order requested in review:

  1. Full-file integrity (labels, timestamps, duplicates, missing/invalid values).
  2. Attack episodes, benign counts, time gaps, natural class proportions.
  3. Representative attack sampling across each entire episode.
  4. Full-file feature analysis (zero/sentinel values, correlations).
  5. Fixed-time vs fixed-flow graph-window feasibility.
  6. Host overlap, topology overlap, time/scenario confounding.
  7. Summary of findings and implications for task construction.

Important: the CSV is stored in time order. The first 1M rows cover only about 18 minutes of the scanning episode, so every claim here is measured over the full 27.5M-row file unless a cell explicitly says otherwise.

Stage 2 — Attack episodes, benign counts, gaps and natural proportions¶

The nine attacks each form one contiguous block after benign removal. This cell:

  1. Derives attack episode boundaries from consecutive same-attack runs.
  2. Counts benign and attack rows per episode and per inter-episode gap using inclusive episode intervals [start, end] and open gap intervals (end, next_start).
  3. Reports natural class proportions (attack prior) per episode.
  4. Lists the gaps (rows outside attack intervals) and their sizes.

Interval convention: every row belongs to exactly one interval — pre, one episode, one gap, or post.

# 2B. Benign counts per episode + gap traffic + natural proportions
# Interval convention:
#   pre     : t < s1                                        (index 0)
#   episode : s_i <= t <= e_i  (inclusive both ends)       (index 2*(i-1)+1)
#   gap_i   : e_i < t < s_{i+1}  (open both ends)           (index 2*i)
#   post    : t > e9                                        (last index)
# Every row belongs to exactly one interval.

n_ep = len(runs)
ep_starts = np.array([r['start'] for r in runs], dtype=np.int64)
ep_ends   = np.array([r['end'] for r in runs], dtype=np.int64)

# Build interval names: pre, ep1, gap1, ep2, gap2, ..., ep9, post
interval_names = ['pre']
for i in range(n_ep):
    interval_names.append(runs[i]['label'])
    if i + 1 < n_ep:
        interval_names.append('gap_' + runs[i]['label'] + '_' + runs[i + 1]['label'])
interval_names.append('post')
n_int = len(interval_names)  # should be 1 + 9 + 8 + 1 = 19

int_total = np.zeros(n_int, dtype=np.int64)
int_ben   = np.zeros(n_int, dtype=np.int64)
int_atk   = np.zeros(n_int, dtype=np.int64)

for ch in pd.read_csv(DATA_PATH, chunksize=CHUNK, usecols=['FLOW_START_MILLISECONDS', 'Label']):
    t = ch['FLOW_START_MILLISECONDS'].to_numpy(dtype=np.int64)
    lab = ch['Label'].to_numpy(dtype=np.int8)

    # ---- Episode rows: s_i <= t <= e_i ----
    cand = np.searchsorted(ep_starts, t, side='right') - 1
    in_ep = (cand >= 0) & (cand < n_ep) & (t <= ep_ends[cand])

    ep_rows = np.flatnonzero(in_ep)
    if len(ep_rows):
        c = 2 * cand[ep_rows] + 1  # episode interval index
        int_total += np.bincount(c, minlength=n_int)
        int_ben += np.bincount(c[lab[ep_rows] == 0], minlength=n_int)
        int_atk += np.bincount(c[lab[ep_rows] == 1], minlength=n_int)

    # ---- Non-episode rows: pre, gap, or post ----
    non_ep = np.flatnonzero(~in_ep)
    if len(non_ep):
        t_ne = t[non_ep]
        lab_ne = lab[non_ep]

        # pre: t < s1
        pre_mask = t_ne < ep_starts[0]
        # post: t > e9
        post_mask = t_ne > ep_ends[-1]
        # gap: everything else
        gap_mask = ~(pre_mask | post_mask)

        pre_rows = np.flatnonzero(pre_mask)
        if len(pre_rows):
            c = np.zeros(len(pre_rows), dtype=np.int64)
            int_total += np.bincount(c, minlength=n_int)
            int_ben += np.bincount(c[lab_ne[pre_rows] == 0], minlength=n_int)
            int_atk += np.bincount(c[lab_ne[pre_rows] == 1], minlength=n_int)

        post_rows = np.flatnonzero(post_mask)
        if len(post_rows):
            c = np.full(len(post_rows), n_int - 1, dtype=np.int64)
            int_total += np.bincount(c, minlength=n_int)
            int_ben += np.bincount(c[lab_ne[post_rows] == 0], minlength=n_int)

            int_ben += np.bincount(gap_idx[lab_gap == 0], minlength=n_int)
            int_atk += np.bincount(gap_idx[lab_gap == 1], minlength=n_int)

Stage 3 — Representative attack sampling across each episode¶

Replace v1's group.head(...) (first 20k rows of each episode) with equal-count, time-stratified sampling across the full span of each attack episode, plus contemporaneous benign flows from the same episode.

Design (per episode):

  • Split the episode into 20 equal-time bins.
  • Draw up to 300 attack flows and 300 benign flows per bin (uniform within bin).
  • Report natural priors (attack share within the episode) and the balanced sample.

This makes the sample representative of the whole episode, not just its start.

NBINS = 20
PER_BIN = 300
SAMPLE_SEED = 0
rng = np.random.default_rng(SAMPLE_SEED)
print('Sampling RNG        : numpy.random.default_rng')
print('Sampling seed       :', SAMPLE_SEED)

# Read column names once (fast, nrows=0)
df0_cols = pd.read_csv(DATA_PATH, nrows=0).columns.tolist()

# Precompute episode arrays for fast lookup
ep_starts = np.array([r['start'] for r in runs], dtype=np.int64)
ep_ends   = np.array([r['end'] for r in runs], dtype=np.int64)
ep_names  = np.array([r['label'] for r in runs], dtype=object)
n_ep = len(runs)

# Bucket key = (episode_index, bin, class) where class: 0=attack, 1=benign
n_buckets = n_ep * NBINS * 2
bucket_count = np.zeros(n_buckets, dtype=np.int64)   # total rows seen per bucket
bucket_res = [[] for _ in range(n_buckets)]           # reservoir of (row_id, values...)

n_rows_seen = 0  # global CSV row ordinal, used to verify sample uniqueness

for ch in pd.read_csv(DATA_PATH, chunksize=CHUNK,
                      usecols=None):  # full row needed for sample
    t = ch['FLOW_START_MILLISECONDS'].to_numpy(dtype=np.int64)
    lab = ch['Label'].to_numpy(dtype=np.int8)

    chunk_row_ids = np.arange(n_rows_seen, n_rows_seen + len(ch), dtype=np.int64)
    n_rows_seen += len(ch)

    # ---- Assign each row to an episode (inclusive [start, end]) ----
    cand = np.searchsorted(ep_starts, t, side='right') - 1
    in_ep = (cand >= 0) & (cand < n_ep) & (t <= ep_ends[cand])
    if not in_ep.any():
        continue

    vi = np.flatnonzero(in_ep)
    ei = cand[vi]                              # episode index (0-based)
    st_arr = ep_starts[ei]
    en_arr = ep_ends[ei]
    span = en_arr - st_arr
    span = np.where(span == 0, 1, span)
    bi = np.floor((t[vi] - st_arr) / span * NBINS).astype(np.int16)
    np.clip(bi, 0, NBINS - 1, out=bi)
    cls = (lab[vi] == 0).astype(np.int8)       # 0=attack, 1=benign

    # Bucket key: ((ei * NBINS) + bi) * 2 + cls
    bk = ((ei * NBINS + bi) * 2 + cls).astype(np.int64)

    # ---- Reservoir sampling per bucket ----
    for bucket in np.unique(bk):
        rows = vi[bk == bucket]
        chunk_data = ch.iloc[rows].to_numpy()  # 2D array, one row per selected flow
        chunk_ids = chunk_row_ids[rows]
        n_new = len(rows)
        n_seen_before = int(bucket_count[bucket])
        n_bucket_total = n_seen_before + n_new
        bucket_count[bucket] = n_bucket_total

        res = bucket_res[bucket]
        cap = PER_BIN

        # Phase 1: fill reservoir if not yet full (positions < cap)
        fill_end = min(n_bucket_total, cap)
        if n_seen_before < fill_end:

            for i in range(fill_local_end):
                res.append((int(chunk_ids[i]),) + tuple(chunk_data[i]))

        # Phase 2: reservoir replacement for positions >= cap
        replace_start = max(n_seen_before, cap)
        if n_bucket_total > replace_start:
            replace_positions = np.arange(replace_start, n_bucket_total)
            probs = cap / (replace_positions.astype(float) + 1.0)
            do_replace = rng.random(len(replace_positions)) < probs
            if do_replace.any():
                # Offsets into this chunk: global position minus rows seen before it
                replace_offsets = replace_positions[do_replace] - n_seen_before
                replace_data = chunk_data[replace_offsets]
                replace_ids = chunk_ids[replace_offsets]
                replace_idx = rng.integers(0, cap, size=len(replace_offsets))
                for i, j in enumerate(replace_idx):
                    res[int(j)] = (int(replace_ids[i]),) + tuple(replace_data[i])

Stage 7 — Summary of findings and implications for task construction¶

What we measured (full file, 27,520,260 flows)¶

Finding Implication
9 attack types, each one contiguous time block Attacks are sequential by capture period, not mixed
Attack share per episode ranges 0.3%–90.6% Natural priors differ wildly; balanced sampling needed
Only 18,768 rows (0.068%) lie outside attack intervals Almost every flow is inside an attack scenario window
Attack-specific source-host sets are tiny (2–17 hosts) Host-related confounding is possible within an episode
6 of 9 attacks share 100% of source hosts with benign; Scanning/DoS/DDoS have 12–33% exclusive hosts Host identity is not a general separator, but host overlap varies by episode
Source/destination Jaccard between attack classes is near 0 Attack classes use nearly disjoint hosts, consistent with scenario confounding
Sample: 98,348 flows, seed 0, 0 duplicate source IDs, 352/360 non-empty buckets The stratified sample is unique and reproducible
Injection covers 18/20 time bins; Ransomware covers 16/20 These are true capture gaps, not sampling errors
1s windows: 39.4% empty, median 16 flows Very sparse; fixed-time windows need care
60s windows: 35.0% empty, median 686 flows More usable but still many empty windows
Fixed-flow windows (N=1000): median span 3.7s, p95 40.9s Flow-count windows compress quiet periods
Fixed-flow windows are segmented at 5-minute idle gaps Windows never span long capture pauses

Limitations (must be stated in any use of this dataset)¶

  1. Scenario confounding: each attack type appears in exactly one time block. Transfer between attack types cannot be disentangled from transfer across capture periods/hosts using ToN-v3 alone.
  2. Single episode per attack: no replication of the same attack under different conditions.
  3. Sparse graphs: many 1s/10s windows are empty; graph construction must handle empty/sparse windows explicitly.
  4. No ground truth beyond Label/Attack: no multi-label or per-flow attack-subtype verification.

Recommended next steps (not implemented here)¶

  • Do not freeze task order, window size, flow cap, or graph-size threshold yet.
  • Decide whether ToN-v3 is suitable given the confounding, or augment with multiple episodes / another dataset.
  • If proceeding, use episode-grouped or window-grouped splits (never random flow-level splits) to avoid leakage.
  • Report both natural-prior and balanced results per episode.

This audit ends here. No task construction or preprocessing code is included.
